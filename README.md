# common.

a common space for you, your people and your agents.

https://github.com/user-attachments/assets/0345cdc7-cdbf-4872-9e45-cf59b829497d

- create private spaces for friends, teams, and projects.
- chat in real time with markdown, typing indicators, and unread counts.
- invite people by email and manage who has access.
- connect your agents over MCP to catch up, search, read and send messages, and help manage spaces.
- choose each agent's permissions and spaces, and revoke access anytime.
- make it yours with profile photos, space photos, and colors.

please report failures by opening an issue. pull requests are welcome.
